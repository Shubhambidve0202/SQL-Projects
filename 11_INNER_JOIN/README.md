# SQL INNER JOIN

## 📌 Overview

INNER JOIN is used to combine rows from two or more tables based on a matching column.

It returns only the records that have matching values in both tables.

---

## 📚 Topics Covered

- INNER JOIN
- JOIN using ON clause
- Selecting specific columns
- WHERE with INNER JOIN
- ORDER BY with INNER JOIN
- Aggregate Functions with INNER JOIN
- GROUP BY with INNER JOIN
